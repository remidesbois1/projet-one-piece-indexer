# Panel Detector Annotation Tool

This folder contains two scripts:

- `download_panel_annotation_dataset.py`: downloads every Supabase page that has at least one bubble and writes `panel_annotation_dataset/dataset.json`.
- `panel_annotator.py`: opens the downloaded pages in Tkinter, lets you draw manga panel rectangles, assigns bubbles to panels, and writes `panel_annotation_dataset/panel_annotations.json`.
- `export_dataset_yolo.py`: converts `panel_annotations.json` into a copied YOLO train/test dataset.
- `train_yolo.py`: fine-tunes YOLO26 on panel boxes, evaluates the best model on the test split, exports ONNX, and writes metrics.
- `run_pipeline.py`: runs export + training + test evaluation.

## Setup

```powershell
pip install -r requirements.txt
```

The downloader reads `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` from `.env` in this folder, `docker_scripts/.env`, or the project root.

## Download

```powershell
python download_panel_annotation_dataset.py
```

Useful options:

```powershell
python download_panel_annotation_dataset.py --limit 20
python download_panel_annotation_dataset.py --status "YOUR_DB_STATUS_VALUE"
python download_panel_annotation_dataset.py --output-dir panel_annotation_dataset
```

The downloader saves all images as JPEG files so the annotation UI does not depend on the original image format.

## Annotate

```powershell
python panel_annotator.py
```

Main controls:

- Drag on the page to create a case rectangle.
- Click a case to select it.
- `Delete` removes the selected case.
- `Left` / `Right` navigate pages.
- `Ctrl+S` saves.
- `Ctrl+mouse wheel` zooms.
- `Assign` moves the selected bubble into the selected case.
- `Unassign` removes the selected bubble from its current case.
- `Auto case` assigns unassigned bubbles inside the selected case.
- `Auto page` recomputes all page assignments by choosing the smallest containing case for each bubble.
- `Up` / `Down` changes case order.
- `Sort RTL` sorts cases with a right-to-left, top-to-bottom heuristic.

## Output

`panel_annotations.json` contains one entry per page:

```json
{
  "page_id": 123,
  "cases": [
    {
      "case_id": "case_1",
      "order": 1,
      "bbox": {"x": 10, "y": 20, "w": 300, "h": 240},
      "bubble_ids": [456],
      "bubbles": [
        {"id": 456, "order": 1, "bbox": {"x": 50, "y": 80, "w": 90, "h": 60}}
      ]
    }
  ],
  "unassigned_bubble_ids": []
}
```

Coordinates are in original image pixels, ready to be converted to YOLO labels.

## Train YOLO26

After annotation, export a YOLO dataset:

```powershell
python export_dataset_yolo.py --test-size 0.2 --seed 42
```

This creates:

```text
dataset/
  data.yaml
  manifest.json
  train/images
  train/labels
  test/images
  test/labels
```

Train and test:

```powershell
python train_yolo.py --model yolo26n.pt --imgsz 800 --epochs 100 --batch 16
```

Or run the full export + training + test pipeline:

```powershell
python run_pipeline.py --model yolo26n.pt --imgsz 800 --epochs 100 --batch 16
```

Useful quick smoke test:

```powershell
python run_pipeline.py --epochs 1 --batch 2 --no-onnx
```

Metrics and artifacts:

- `runs/yolo26n_panel*/weights/best.pt`
- `runs/yolo26n_panel*/panel_metrics.json`
- `metrics/latest_panel_metrics.json`
- `runs/eval/yolo26n_panel_test*` for confusion matrix, curves, prediction JSON, and validation plots generated by Ultralytics.
